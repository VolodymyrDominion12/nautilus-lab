року не переприймати те саме рішення без контексту (docs/27 E-2.8).

## Шаблон

```markdown
# NNNN. Назва рішення

- Статус: запропоновано | прийнято | замінено NNNN
- Дата: РРРР-ММ-ДД

## Контекст
Що змусило вирішувати, які були обмеження.

## Рішення
Що обрано, одним-двома абзацами.

## Наслідки
Що стало простіше, що складніше, що треба робити тепер.
```

Нове рішення — новий номер. Змінене рішення не переписують: пишуть нове й ставлять
старому «замінено NNNN».
