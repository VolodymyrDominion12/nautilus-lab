# Глосарій

> Курс «Теорія трейдингу для nautilus-lab — 2026», частина 12 з 13. Стан на 2026-10-07.

| Термін | Що означає |
| --- | --- |
| Alpha (альфа) | Дохідність понад те, що пояснюється простим утриманням ринку |
| Basis | Різниця ціни ф'ючерса і споту |
| bps (базисний пункт) | 0.01%. 10 bps = 0.1% |
| Breakeven cost | Витрата на одиницю обороту, за якої PnL = 0 |
| Buy&hold, vol-matched | Просте утримання; те саме, масштабоване до волатильності стратегії |
| Calmar | Річна дохідність / максимальна просадка |
| Carry | Дохід від утримання позиції (funding, відсоток), незалежно від руху ціни |
| Circuit breaker | Автоматична зупинка торгівлі при перевищенні ліміту |
| Cointegration | Стаціонарна лінійна комбінація двох нестаціонарних рядів |
| CPCV / CSCV | Комбінаторна очищена крос-валідація / комбінаторно симетрична — основа PBO |
| DSR | Deflated Sharpe: ймовірність, що Sharpe справжній, з поправкою на кількість спроб |
| Embargo / purging | Зазор і видалення прикладів біля межі IS/OOS, щоб мітки не текли в тест |
| Fail closed | При невизначеності система відмовляє, а не діє за умовчанням |
| Fill model | Правила, як симулятор виконує заявки (ціна, час, проковзування) |
| Funding rate | Періодичний платіж між лонгами і шортами на перпах |
| Hawkes process | Модель подій, де кожна подія тимчасово підвищує імовірність наступних |
| Holdout | Запечатані дані, які розкривають один раз для фінальної перевірки |
| IS / OOS | In-sample (де обирають параметри) / out-of-sample (де лише звітують) |
| Kelly | Частка капіталу, що максимізує довгостроковий ріст. На практиці беруть частку від неї |
| Lookahead bias | Використання в рішенні інформації, яка в той момент ще не була відома |
| Maker / taker | Хто додає ліквідність у книгу / хто її забирає. Taker платить більше |
| Meta-labeling | Модель, яка вирішує, чи брати сигнал іншої стратегії |
| MFT / HFT | Середньочастотна (хвилини–дні) / високочастотна (мілісекунди) торгівля |
| Open interest | Кількість відкритих контрактів на деривативі |
| PBO | Ймовірність, що переможець на IS опиниться нижче медіани на OOS |
| Perpetual (перп) | Ф'ючерс без дати експірації, прив'язаний до споту через funding |
| Point-in-time | Дані в тому вигляді, в якому вони були доступні на ту дату |
| Preregistration | Запис гіпотези, параметрів і критеріїв до прогону |
| R (у «9.5R») | Збиток у одиницях запланованого ризику на угоду |
| Sharpe / Sortino | Дохідність на одиницю волатильності / на одиницю низхідної волатильності |
| Slippage | Різниця між очікуваною і фактичною ціною виконання |
| Survivorship bias | Спотворення через те, що в даних лише активи, що вижили |
| Triple barrier | Мітка за тим, що ціна торкнеться першим: тейк-профіту, стопу чи часової межі |
| Turnover | Проторгований ноціонал на одиницю капіталу |
| Vol targeting | Розмір позиції обернено пропорційний прогнозній волатильності |
| VPIN | Volume-synchronized probability of informed trading — міра токсичності потоку заявок |
| Walk-forward | Послідовні пари «навчився — протестував», що рухаються вперед у часі |
