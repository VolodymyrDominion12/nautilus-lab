## Що зробити після оновлення

1. **Перетренувати моделі з явним кінцем вікна**, інакше ML-роботи не запустяться:

   ```bash
   uv run lab ml train --model-type formulaic --instrument ETH/USDT.SIM --interval 1h \
       --end 2025-11-15 --output models/formulaic_eth_1h.txt
   ```

   `--end` має бути раніше першого OOS-бару. Вікна фолдів без жодного бектесту
   записує `lab research --robot formulaic_lgbm --folds 4 --register "..."` у файл
   реєстрації (`research/preregistrations/`).
2. Перезапустити тір A матриці з чистої ревізії (без `+dirty`) — це нова базова лінія.
   Числа `pairs` і всіх ML-роботів з попередньої матриці більше не порівнювані.

## Що свідомо не зроблено тут

- Research-профіль ризику (`DRAWDOWN_COOLDOWN_DAYS`, vol-target) і нова планка гейта —
  це зміни методології. Вони йдуть окремим ADR **до** прогонів хвилі 6.
- Навчання моделі всередині кожного фолда: картка вже не дає використати модель, що
  бачила OOS; пофолдове навчання — наступний крок.
- Paper-стрімер для `formulaic_lgbm` досі використовує евристичний класифікатор.
