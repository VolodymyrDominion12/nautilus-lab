# 0004. Типи фронтенду генеруються з Pydantic, без `openapi-typescript`

- Статус: прийнято
- Дата: 2026-09-25

## Контекст

Типи відповідей API були переписані вручну в `frontend/src/services/api.ts` і
розходились із тим, що сервер реально шле. План E-2.3 називав `openapi-typescript`.

## Рішення

Відповіді описують Pydantic-моделі (`api/responses.py`, з `extra="allow"`, щоб жодне поле
не губилось), `scripts/gen_api_types.py` перетворює їхні JSON-схеми на
`frontend/src/services/api.gen.ts`. Перевірка дрейфу — у `pytest`
(`tests/unit/test_api_types.py`): файл актуальний і кожна модель збігається з реальною
відповіддю маршруту.

## Наслідки

Не потрібні Node, запущений застосунок і нова npm-залежність; перевірка йде в тому ж CI,
що й решта Python. Генератор підтримує лише ту частину JSON-схеми, яку використовують
моделі, і падає на решті замість мовчазно неправильного типу. Маршрути, що віддають
дані з файлів, переходять на моделі лише після нормалізації на сервері: строга модель над
неперевіреним вмістом перетворила б погані дані на HTTP 500.
