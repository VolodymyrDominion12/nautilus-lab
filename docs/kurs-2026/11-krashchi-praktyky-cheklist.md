# Кращі практики 2026: чекліст

> Курс «Теорія трейдингу для nautilus-lab — 2026», частина 11 з 13. Стан на 2026-10-07.

Лабораторія вже виконує більшість пунктів з дослідницької дисципліни. Найбільші прогалини — у даних (мало монет і років) та в тому, що гіпотези досі стоять на годинних барах. Позначки відображають стан за документами проєкту на 7 жовтня; можеш відмічати їх сам.

## Дослідницька дисципліна

- [x] Пороги гейта зафіксовані в коді до прогонів, зміни — лише через ADR
- [x] Попередня реєстрація і журнал спроб, кожен перемикач дає новий `trial_id`
- [x] Walk-forward з purging і embargo в часі мітки
- [x] PBO і DSR як обов'язкові перевірки, невиміряне не читається як «так»
- [x] Двофазний гейт: спершу альфа (gross, breakeven), потім нетто за класом
- [ ] Картка гіпотези з економічним механізмом, бюджетом спроб і kill-критерієм (`research/hypotheses/`)
- [ ] Зони даних exploration / validation / holdout з гардом у коді
- [ ] Перестановочна нульова модель у звіті кожного прогону
- [ ] Чисте дерево git для кожного виміру, без `+dirty`

## Дані і витрати

- [ ] Широкий всесвіт: point-in-time топ-30 з 2019 року, з делістованими монетами
- [ ] Перпи і funding з 2020 року, funding у PnL
- [ ] Профілі витрат під реальний акаунт (спот 7.5/7.5 bps, перпи ≈ 1.8/4.5 bps) і стрес × 1.5
- [x] Каталог aggTrades з публічного архіву
- [ ] Збір L2-стакану на VPS, якщо вирішиш повертатися до мікроструктури

## Стратегії і ризик

- [ ] Перейти на 4h/1d для сигналів з breakeven < 20 bps на 1h
- [ ] Vol targeting замість 0.5% ризику на стоп для трендових оверлеїв
- [ ] Circuit breaker з періодом відновлення, вимір сигналу — без нього
- [ ] Портфель кількох слабкових стратегій (risk parity) замість пошуку однієї ідеальної
- [ ] Стрес-слайси `covid2020`, `ftx2022` і 10.10.2025 з машинною перевіркою
